# Changelog

## v0.1.1 — Product experience update

- Introduced the AvatarKit aperture, portrait, and waveform brand mark throughout the application.
- Added a dedicated Models screen with one-click engine setup, persistent background operations, storage guidance, and live setup logs.
- Added downloadable model setup logs, generation logs, full log bundles, and diagnostic reports.
- Reorganized Settings around generation defaults, model management, storage, cleanup, and support.
- Replaced heavyweight engine imports during routine status polling with fast local readiness checks.
- Improved compact navigation accessibility and verified the dark, paper, desktop, and mobile layouts.

## v0.1.0 — Initial public release

- Local talking-avatar generation using SadTalker and Chatterbox.
- GPU-first and CPU compute modes.
- Local generation library, diagnostics, storage controls, dual themes, and one-line installers.
